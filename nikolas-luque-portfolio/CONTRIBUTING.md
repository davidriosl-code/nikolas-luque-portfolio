# Contribuir

Las mejoras de accesibilidad, rendimiento, documentación y calidad del código son bienvenidas.

1. Crea una rama para un cambio concreto.
2. Mantén la separación entre comandos locales y llamadas de IA del servidor.
3. Ejecuta `pnpm typecheck`, `pnpm test`, `pnpm check:secrets` y `pnpm build`.
4. Describe qué problema resuelve el cambio y cómo lo comprobaste.

No añadas credenciales, archivos `.env.local`, datos privados ni recursos visuales sin permiso de reutilización. Los cambios en permisos, voz, pagos de API o acciones externas deben explicar claramente el nuevo comportamiento.
